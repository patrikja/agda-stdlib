** 2. The "Split View" & Induction Principle
+ Standard pattern matching on Lehmer codes (splitting at index 0) isn't enough for clean proofs.
+ We can benefit from an induction principle based on splitting at an arbitrary index |i| into |Split pi ps'| such that |extend i p_i ps' == ps|.

+ [ ] Finalize |PView| :: Ensure |splitView i ps| correctly extracts |(i, pi)| and the "remaining" permutation |ps'|.
+ [ ] |extend| / |splitView| Round-trip :: Prove |splitView-spec|: |splitView i (extend i pᵢ ps) ≡ Split pᵢ ps|. This is the "correctness" of the view.
+ [ ] View-based Composition :: Implement (or prove equivalent) the "intelligent" composition that uses the view. This may make |inverse-prop₂| significantly easier.
  #+BEGIN_SRC agda
  compose : Permutation n → Permutation n → Permutation n
  compose ps (i :- qs) with splitView i ps
  ... | Split pᵢ ps' = pᵢ :- (ps' ∙ qs)
  #+END_SRC

** 3. Integration with Existing |Data.Fin.Permutation|
+ The current *stdlib* uses a "record of bijections" while the "Lehmer code" approach is a first-order representation.
